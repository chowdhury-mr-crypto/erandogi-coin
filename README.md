# EranDogi.com
Premium mobile-first virtual mining website.

## Included
- Landing page
- Mining dashboard
- 0.010 DOGI/min demo rate
- 24-hour session
- Local demo state
- Responsive premium UI

## Important
The included dashboard is a front-end demo. It is NOT a real blockchain miner and does not create a real cryptocurrency. For a production multi-user system, use a server-side backend and database for balances, sessions, referrals and withdrawals.

## Free hosting
Cloudflare Pages can host this static site for free and gives a `*.pages.dev` address. Connect this GitHub repository, use `main` as production branch, build command `exit 0`, and output directory `.`.

A true `EranDogi.com` `.com` domain is not normally free; you need to register/own it, then connect it to Cloudflare Pages.
