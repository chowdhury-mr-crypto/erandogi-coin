Questions, answered.

Is this real blockchain mining?

The starter site is a virtual reward/mining model. It does not use your device to mine a blockchain.

Does mining continue when I close the browser?

The production architecture should calculate elapsed time from server timestamps. The included demo uses browser storage only.

Can ads be added later?

Yes, ad placements can be added to the dashboard/task system.
